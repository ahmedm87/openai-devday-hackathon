# OpenAI DevDay Hackathon

Shared workspace for our hackathon team.

## Project

Add the problem we are solving, our target users, and the demo goal here once the team agrees on an idea.

## Get started

```sh
git clone https://github.com/ahmedm87/openai-devday-hackathon.git
cd openai-devday-hackathon
git switch -c feature/your-feature
```

The application stack and setup commands will be added when implementation starts.

## Team workflow

- Track tasks in GitHub Issues and assign an owner.
- Work on a feature branch and open a pull request into `main`.
- Include a short description and how you checked your change.
- Keep API keys in local environment variables; never commit secrets.

## Hackathon checklist

- [ ] Agree on the problem and demo goal
- [ ] Choose the application stack
- [ ] Split tasks across the team
- [ ] Build and test the core demo
- [ ] Add setup instructions and a demo link
- [ ] Prepare the final pitch

## Team access

This repository is private. The owner can invite teammates through Settings → Collaborators using their GitHub usernames.
